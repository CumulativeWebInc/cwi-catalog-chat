🤖 Ask the CWI Catalog

An automated bot for Cumulative Web Inc. Answers only from verified catalog data — every fact carries its evidence tier and last-checked date. This demo runs the exact engine that powers the WhatsApp bot.

Evidence tiers: catalog-verified (from cwi-learn/catalog.json) · placement-verified (full playlist scan) · claim-flagged (claimed, not verified — never a verdict) · unverified (known unknown). Values older than 48h are labeled stale, never refreshed silently. Dataset: data.json · Engine: engine.js (zero dependencies, MIT-style open).
